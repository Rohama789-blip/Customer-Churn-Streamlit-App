# Customer Churn Prediction Streamlit App

## Project Overview

This project is a machine learning web application that predicts whether a telecom customer is likely to churn. The model was trained using the Telco Customer Churn dataset and deployed with Streamlit Community Cloud to provide an easy-to-use prediction interface.

## Features

- Customer churn prediction using Logistic Regression
- Simple and interactive Streamlit interface
- Real-time prediction
- Deployed on Streamlit Community Cloud
- Model saved using Joblib

## Dataset

Dataset: Telco Customer Churn Dataset

## Installation

Clone the repository:

```bash
git clone https://github.com/Rohama789-blip/Customer-Churn-Streamlit-App.git
```

Go to the project folder:

```bash
cd Customer-Churn-Streamlit-App
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
